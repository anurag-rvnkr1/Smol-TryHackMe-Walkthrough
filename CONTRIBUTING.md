# Contributing

Thanks for improving the documentation.

## Standards

Keep contributions reproducible, technically specific, and scoped to the TryHackMe lab. Prefer clear command blocks, short evidence-driven explanations, and defensive context.

## Do not add

- Real-world credentials or personal data
- Unredacted flags intended to bypass the learning flow
- Credentials or keys copied from systems outside the lab
- Claims that are not supported by the room evidence

## Pull requests

A good documentation PR should include a concise summary, the relevant section(s), any new visual evidence, and a note explaining how the change was validated.
